# Divine Interiors

Modern architecture and turnkey luxury interior fit-out web experience inspired by Ronn Square design systems, bespoke micro-interactions, and GSAP scroll-driven animations.

## Live Pages
- **Home**: `index.html`
- **About Us**: `about.html`
- **Projects**: `projects.html`
- **Realisations**: `realisations.html`

## Features
- **GSAP & ScrollTrigger Animations**: Precision scroll scrub, totems, and section reveals.
- **Interactive Totems & Physics**: Balancing sway totems and dynamic split-text highlighting.
- **Barba.js Seamless Transitions**: Fluid page-to-page navigation with curved wipe transitions.
- **Full Brand System**: Adapted for Divine Interiors with custom typography and curated assets.
